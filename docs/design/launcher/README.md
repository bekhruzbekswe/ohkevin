# The launcher, as it was

The menu-bar launcher (Chrome call window) before it was removed: every state, light and dark, at 2×, kept as the design
record. `panel/` is every panel, the menu-bar item (`*-menu`), Settings (`settings-*`), the setup screen (`setup-*`), the
update line (`line-*`), the choosers, focus rings, the brand and the privacy page, drawn by `LauncherChecks --snapshots`.
`call/` is the call window as the launcher showed it, the call page's own demo scenes.
