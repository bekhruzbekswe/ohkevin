# 7. Apache License 2.0

Status: decided, November 2026.

## Context

Oh Kevin is free and open source. MIT and Apache 2.0 were the candidates.

## Decision

Apache License 2.0, with a `NOTICE` file.

## Why

- As permissive as MIT, plus an explicit patent grant from contributors.
- `NOTICE` gives one place to list what we ship and what is downloaded at install, with each licence.

## Consequences

- No GPL code in the repository or the releases (see decision 5).
- Anthropic's SDK and Claude Code stay under Anthropic's own terms.
